# google-flow-fix

Userscript для Tampermonkey, предназначенный для устранения сообщения «Flow ещё не работает в вашей стране» в Google Flow.

## 📋 Установка

1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/) для своего браузера.
2. Нажмите правой кнопкой мыши на значок Tampermonkey и откройте настройки.
3. Включите опцию **«Разрешить пользовательские скрипты»**. Подробная инструкция: [Tampermonkey FAQ](https://www.tampermonkey.net/faq.php?q=Q209#Q209).
4. Нажмите на значок Tampermonkey и выберите **«Создать новый скрипт»**.
5. Удалите стандартный код редактора и вставьте содержимое файла: https://github.com/gritsienkoartem/google-flow-fix-Russia-/blob/main/google.flow.fix.js.
6. Сохраните изменения (`Ctrl + S`) и закройте вкладку редактора.
7. Откройте [Google Flow](https://flow.google.com).

## 🛠 Требования

- Браузер с поддержкой Tampermonkey.
- Установленное расширение Tampermonkey.
- Доступ к Google Flow.
